# DPBPS – Deployment‑Phase‑Aware Bottleneck‑Prioritized Scaling Platform\n\n## Overview\n\nThis repository contains a research‑grade web platform for monitoring, simulating, and evaluating dynamic scaling strategies in microservices applications. It includes a modern React+TypeScript frontend built with Vite and Tailwind CSS, and a Python FastAPI backend providing a versioned REST API.\n\nThe project is organized into four main sections:\n\n- **frontend/** – React UI, components, pages, and design system.\n- **backend/** – FastAPI service, data models, and business logic.\n- **infrastructure/** – Dockerfiles, Kubernetes manifests, Prometheus & Grafana configuration (future).\n- **experiments/** – Configuration files, results, and reporting utilities.\n\nSee the `docs/` directory for detailed architecture, setup instructions, and implementation plans.\n\n---\n\n*This is the initial scaffold for Phase 1. Further development will flesh out the UI, backend endpoints, and integration with simulated and real micro‑service environments.*
